One sentence, at most 200 characters, explaining the modern internet to a traveler from 1800 — using only words that plausibly existed in 1800. Instead of the crowded library / post-office / road picture, it builds on a great market square: more books, letters, and songs on the stalls than any man could read in a lifetime, and anything asked for taken in the blink of an eye.

## Run it

```sh
node main.ts
```

Writes the sentence to `/output/entry.txt` (187 characters, one sentence, no trailing newline).
